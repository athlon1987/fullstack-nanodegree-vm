**Acquisition route.** The publishers' own sites (kenney.nl, quaternius.com, poly.pizza, itch.io, sketchfab, fab, mixamo) are not reachable from this build environment's network policy. The models below were acquired from the npm package [`@netforge/asset-library-files@0.2.0`](https://www.npmjs.com/package/@netforge/asset-library-files), an optimised redistribution of CC0 packs whose NOTICE records, per pack, where the licence was verified. Every file is checked against that package's sha256 index on import (`npm run assets:import`); a mismatch aborts the import. Original files are preserved untouched in `asset-sources/netforge/` together with `NOTICE`, `CC0-1.0.txt` and the per-asset provenance manifest (`manifest-lowpoly.json`, which includes each Quaternius model's Poly Pizza page).

**Status legend.** Acquired = file present and verified. Pending = identified, not yet obtained. Unavailable = blocked or not licensable.
